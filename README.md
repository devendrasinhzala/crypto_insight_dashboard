# Crypto Insight Dashboard

A Flutter application that displays cryptocurrency market insights with a clean and responsive UI.

## Features

* Crypto dashboard with pagination
* Pull-to-refresh
* Search functionality
* Coin details screen
* Volatility score calculation
* Recent viewed coins
* Local persistence using Hive
* Interactive price graph
* Responsive Material 3 UI

---

## Tech Stack

* Flutter
* Bloc
* Clean Architecture
* Dio
* Hive
* Freezed
* fl_chart

---

## Architecture

The project follows:

* Clean Architecture
* Modular Folder Structure
* Repository Pattern
* Feature-wise separation
